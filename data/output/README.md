# Output Data / 输出数据

Runtime outputs belong here: the exact seven-column `offers.csv`, separate `internal_analysis.csv`, and `errors.csv` diagnostics. The final offers file is published only after all valid records have successful validated messages.

运行结果写入此处：严格七列的 `offers.csv`、独立的 `internal_analysis.csv` 和 `errors.csv` 诊断文件。仅当全部有效记录均成功生成并通过消息校验后，才发布最终 offers 文件。

Generated customer data is local and should not be committed.

生成的客户数据仅供本地使用，不应提交到版本库。
