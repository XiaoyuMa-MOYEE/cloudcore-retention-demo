# Cloudflare Python Backend / Cloudflare Python 后端

`worker.py` is the Cloudflare Python Worker entrypoint. It hosts the stateless FastAPI app in `cloudflare_app.py`, which reuses the existing `src/` Python business rules, copied into Pywrangler's generated module directory before bundling. One request validates and processes the CSV in memory and returns the results; it writes no server-side upload, task, checkpoint, database, or result file. / `backend/worker.py` 是 Cloudflare Python Worker 入口；它承载 `backend/cloudflare_app.py`，后者复用现有 `src/` Python 业务规则，并在打包前复制到 Pywrangler 生成的模块目录。单次请求在内存中校验并处理 CSV 后返回结果；不在服务器写入上传、任务、检查点、数据库或结果文件。

For local web development, run `uvicorn backend.cloudflare_app:app --reload` from the project root and set `AZURE_OPENAI_API_KEY` in ignored `.env` or the process environment. On Cloudflare, configure the key as Worker Secret `AZURE_OPENAI_API_KEY`. / 本地网页开发时，在项目根目录运行 `uvicorn backend.cloudflare_app:app --reload`，并将 `AZURE_OPENAI_API_KEY` 配置到被忽略的 `.env` 或进程环境；Cloudflare 上配置为 Worker Secret `AZURE_OPENAI_API_KEY`。
