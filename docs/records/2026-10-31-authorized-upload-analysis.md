# Authorized Uploaded CSV Analysis / 已授权上传 CSV 分析

- Scope / 范围: Following the user's confirmation that external processing of the intended real dataset is authorized, the web Worker now permits any uploaded CSV that passes the existing local schema validation to proceed when the user clicks **Run AI Analysis**. The page still loads the bundled synthetic dataset on first visit, and upload validation alone makes no model call. / 用户确认目标真实数据已获外部处理授权后，网页 Worker 允许任何通过现有本地 Schema 校验的上传 CSV 在用户点击 **Run AI Analysis** 后进入分析。首次访问仍加载捆绑模拟数据；仅上传校验不会调用模型。
- Governance / 数据治理: The Worker remains public and has no login; any visitor can submit a valid CSV and trigger Azure processing. The existing model allowlist is unchanged: industry, products, tenure, support tier, selected offer code, and batch-local IDs. Customer ID, region, MRR, and churn score remain local. / Worker 仍公开且无登录；任何访问者均可提交有效 CSV 并触发 Azure 处理。模型字段允许列表不变：行业、产品、Tenure、Support Tier、选定 Offer 代码及批次内 ID。客户 ID、地区、MRR 和 Churn Score 保留在本地。
- Business behavior / 业务行为: Python input validation, Playbook, Offer/Reason, internal analysis, batch size, Azure provider, Message validation, and seven-column output are unchanged. / Python 输入校验、Playbook、Offer/Reason、内部分析、批次大小、Azure Provider、Message 校验及七列输出均未改变。
- Recovery / 恢复: Web processing remains synchronous and stateless. Failed requests retain no upload or partial result; the user must submit again. / 网页处理仍为同步无状态。失败请求不保留上传文件或部分结果；用户需重新提交。
- Verification / 验证: Updated the existing Mock Provider regression expectations to cover a non-SIM customer ID and the model payload allowlist. Automated tests and frontend build were not run in this change. No live Azure request was made. / 已更新现有 Mock Provider 回归测试，覆盖非 SIM 客户 ID 和模型请求字段允许列表。本次未运行自动化测试或前端构建，也未调用真实 Azure API。
