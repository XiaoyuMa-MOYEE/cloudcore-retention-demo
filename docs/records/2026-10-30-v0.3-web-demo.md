## Known operational choice / 当前部署选择

Cloudflare Python Worker is not used as the Python business host because the Python Worker filesystem is isolate-local/ephemeral, while the current pipeline persists atomic checkpoint and result files. A standalone FastAPI container on a mounted persistent volume preserves the tested Python core. Cloudflare hosts/proxies the front end and API path. / 不使用 Cloudflare Python Worker 承载 Python 业务，因为 Worker 文件系统按隔离实例易失，而现有管线需原子持久化检查点和结果；独立 FastAPI 容器挂载持久卷可复用已测试核心，Cloudflare 承载前端并代理 API。
