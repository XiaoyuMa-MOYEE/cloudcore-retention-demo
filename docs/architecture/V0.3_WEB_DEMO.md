# V0.3 Web Demo Architecture / V0.3 Web Demo 架构

## Topology / 部署拓扑

```text
Browser (cloudcore.moyee.uk)
  ├─ Cloudflare Pages: React + TypeScript + Vite static assets
  └─ /api/* → Cloudflare Worker reverse proxy → standalone FastAPI container
                                               ├─ existing Python Core + Azure Provider Adapter
                                               └─ persistent disk: SQLite task registry, source uploads,
                                                  checkpoint, result CSV, local diagnostics
```

Cloudflare Python Workers can run FastAPI, but this application relies on the regular OpenAI Python SDK, Python file operations for atomic pipeline artifacts, environment-based key loading, and resumable checkpoints. Python Worker filesystems are ephemeral per isolate, so this implementation keeps execution in a conventional Python container and uses Cloudflare only for the static front end and request routing. No customer logic is duplicated in TypeScript. / Cloudflare Python Workers 支持 FastAPI，但本项目依赖标准 OpenAI Python SDK、Python 原子文件操作、环境变量密钥读取及可恢复检查点。Python Worker 文件系统是隔离且易失的，因此业务运行放在标准 Python 容器，Cloudflare 仅负责静态前端和请求路由。TypeScript 不复制客户业务逻辑。

## Request and data boundaries / 请求与数据边界

- The browser receives the bundled synthetic 45-row CSV from `/api/demo`; page load never starts model work. / 浏览器从 `/api/demo` 读取随项目提供的 45 条模拟数据；页面加载不会启动模型调用。
- Input is validated using `src.input_validation.validate_csv`; uploaded bytes are retained unchanged and never normalized. Invalid input returns row/field errors. / 输入复用 Python 校验；上传字节原样保留，不做规范化。错误返回行号和字段问题。
- Azure runs default to the exact bundled simulation file, guarded by server-side SHA-256 equality. Uploaded data can be model-processed only if an administrator sets `ALLOW_UPLOADED_SYNTHETIC_ANALYSIS=true`; the browser has no override control. Keep this disabled unless the service is dedicated to synthetic files. / Azure 默认只处理经 SHA-256 核对的项目模拟文件。上传文件只有管理员设置 `ALLOW_UPLOADED_SYNTHETIC_ANALYSIS=true` 后才能送模型；浏览器无法更改该策略。除非服务仅用于合成文件，否则保持关闭。
- Sessions use an HMAC-signed, expiring `HttpOnly; Secure; SameSite=Strict` cookie. The shared access code, signing key and Azure key are server environment secrets. No credential is stored in browser storage. / 会话使用有过期时间的 HMAC 签名 Cookie。访问码、签名密钥、Azure 密钥仅存于服务端环境；浏览器不保存认证密钥。
- `run_live()` continues to assign Offer/Reason, calculate the internal index, batch and validate Message, checkpoint, retry, and publish the exact seven output columns. The web layer isolates each task's paths under its persistent runtime directory. / `run_live()` 继续负责 Offer/Reason、内部指标、分批、Message 校验、检查点、重试及七列输出；Web 层为各任务隔离运行文件路径。
- Task status and checkpoint files live on the API container's persistent disk, never on a Worker local filesystem. A restarted `running` task becomes `interrupted`; retry reuses valid checkpoint entries. Completed status is returned only when the pipeline succeeds and the seven-column export exists. / 状态和检查点位于 API 容器持久磁盘，而非 Worker 本地盘。服务重启后运行中任务改为 `interrupted`；重试复用有效检查点。只有核心处理成功且七列文件存在时才返回完成。

## Deployment responsibilities / 部署责任

The repo contains a Render-compatible Docker API service definition and a Cloudflare Pages + Worker proxy definition. The backend host is a separate service; Cloudflare DNS and Worker routing only use `cloudcore.moyee.uk` and `/api/*`. No personal-site source, configuration, repository, or root-domain route is included. / 仓库附带容器 API 服务模板和 Cloudflare Pages/Worker 代理配置。后端是独立服务；Cloudflare DNS 与 Worker 路由只使用 `cloudcore.moyee.uk` 和 `/api/*`，不包含个人主站源代码、配置、仓库或根域路由。

## Limits / 限制

This is a lightweight shared-access demo, not production SaaS. The shared access code has no per-person identity or audit attribution. Task records and customer-level outputs are retained on the mounted disk until an operator removes them. No automatic retention/deletion policy is currently implemented. / 这是轻量共享访问演示，不是生产 SaaS。共享码无法区分个人身份。任务和客户级输出会保留在挂载盘，直至运维人员清理；当前没有自动保留/删除策略。
